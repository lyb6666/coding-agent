========================================
        编程智能体（coding agent）
========================================

一个从零手写的命令行编程智能体：通过与大语言模型交互，自主读写
文件、执行命令，独立完成交给它的编程任务，类似一个简化版的
Claude Code。项目不使用任何 agent 框架或 SDK，主循环、工具系统、
上下文管理、错误处理等核心逻辑全部自行编写。选用 Python 实现，
默认调用 DeepSeek 模型，密钥经环境变量管理。

----------------------------------------
一、Git 仓库地址
----------------------------------------
https://github.com/lyb6666/coding-agent

----------------------------------------
二、如何运行
----------------------------------------
1. 安装依赖：pip install -e .（同时装好全局命令 coding）
2. 配置密钥：复制 .env.example 为 .env，填入 DEEPSEEK_API_KEY
3. 交互启动：在任意目录敲 coding（或 python main.py）
   单次执行：coding "你的编程任务"

----------------------------------------
三、特色功能
----------------------------------------
· 零框架手写：主循环、工具系统、上下文管理全部自己实现，
  只用 OpenAI 兼容客户端与模型原生 tool calling 接口
· 规划-执行分离：先规划步骤、再逐步执行，行为可预测、可审查
· 本地执行 8 类工具：读写/编辑/删除/移动文件、执行命令、列目录、搜索代码
· 上下文管理：token 超限时自动压缩成摘要，保留任务目标与最新进展
· 安全边界：危险命令询问确认（默认拒绝）、拦截常驻服务命令、
  路径限定在工作目录内
· 健壮性：死循环与连续失败检测、指数退避重试、命令输出截断、
  环境感知（OS 命令语法与工作目录）
· 会话持久化：每个文件夹存 .coding_history.json，跨终端恢复对话
· 交互体验：彩色终端、全局 coding 命令、help/tools/reset 命令

----------------------------------------
四、使用示例
----------------------------------------
输入「写一个 Python 脚本，生成 10 个随机数并计算平均值」，
agent 会先输出步骤计划（写脚本 → 运行验证 → 汇报结果），再
逐步执行，最后给出总结，整个过程在彩色终端里清晰可见。也可以
让它修 bug：把报错信息交给它，它会读文件、定位问题、改写后
重新运行验证。

----------------------------------------
五、项目结构
----------------------------------------
coding_agent/    源码包（配置 / 工具 / 主循环 / CLI / 存储）
tests/           单元测试（37 个，运行 python -m pytest）
main.py          程序入口
pyproject.toml   打包与全局命令配置

----------------------------------------
六、设计思路
----------------------------------------
· 规划-执行分离：复杂任务先拆成步骤计划再逐步执行，减少盲目
  试错，也让 agent 的行为可预测、可审查
· 上下文压缩：超限时把旧轮次交给模型压缩成摘要而非直接丢弃，
  用极小 token 保留"已经做到哪一步"的关键进展
· 安全边界：agent 的自主性必须配安全护栏——危险命令默认拒绝并
  询问用户确认，常驻服务命令直接拦截，路径限定在工作目录
· 环境感知：根据操作系统动态注入命令语法提示，避免跨平台时
  生成错误的 shell 命令
· 事件驱动：agent 核心只发结构化事件，终端 UI 负责渲染，
  二者职责分离，便于测试与替换界面

----------------------------------------
七、说明
----------------------------------------
· 默认模型 deepseek-chat，可通过环境变量 DEEPSEEK_MODEL 切换
· 运行时模型与编程语言不限，可切换其它 OpenAI 兼容模型
· API key 仅经环境变量或未入库的 .env 提供，不会出现在仓库中
· 测试命令：python -m pytest
